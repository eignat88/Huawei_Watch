# Анализ структуры донорского `.hwt`

Целевой донорский файл:

```text
assets/hwt/hugo_boss_black.gt-312881-fd38ad7b33.hwt
```

## Статус на момент подготовки

Файл донора отсутствовал в рабочем дереве репозитория, поэтому фактический анализ ZIP-содержимого не выполнен. Каталог `assets/hwt/` подготовлен для добавления файла без переименования.

## Команды для анализа после добавления донора

```bash
python3 tools/inspect_hwt.py assets/hwt/hugo_boss_black.gt-312881-fd38ad7b33.hwt
```

Альтернативно вручную:

```bash
python3 - <<'PY'
from pathlib import Path
from zipfile import ZipFile, is_zipfile
p = Path('assets/hwt/hugo_boss_black.gt-312881-fd38ad7b33.hwt')
print('exists:', p.exists())
print('is_zip:', is_zipfile(p) if p.exists() else False)
if p.exists() and is_zipfile(p):
    with ZipFile(p) as zf:
        for name in zf.namelist():
            print(name)
PY
```

## Что нужно проверить

| Проверка | Ожидаемый результат |
| --- | --- |
| Открывается ли как ZIP | `.hwt` часто является ZIP-подобным архивом, но это не гарантировано для всех поколений устройств. |
| Есть ли `description.xml` | Описывает пакет/проект, если используется старый или совместимый формат. |
| Есть ли `preview/cover.jpg` | Используется как изображение галереи. |
| Есть ли `preview/icon_small.jpg` | Используется как малая иконка. |
| Есть ли `com.huawei.watchface` | Часто является основным бинарным файлом циферблата. |
| Можно ли заменить ресурсы | Нужно проверять экспериментально: бинарь может быть подписан или содержать ресурсы внутри себя. |

## Предварительная оценка возможности простой замены ресурсов

Простая замена `preview/cover.jpg`, `preview/icon_small.jpg` или картинок в ZIP-архиве может изменить только preview. Рабочая часть циферблата может находиться в `com.huawei.watchface`; если этот файл бинарный, сжатый, подписанный или содержит собственную структуру ресурсов, заменить дизайн без полноценной пересборки может быть невозможно.

## Рекомендуемый следующий шаг

1. Добавить донорский `.hwt` в `assets/hwt/`.
2. Запустить `tools/inspect_hwt.py`.
3. Зафиксировать фактическое дерево архива в этом документе.
4. Если ZIP содержит заменяемые ресурсы, сделать тестовую копию в `dist/` и не менять оригинальный донор.
5. Если основной файл бинарный и ресурсов с понятными именами нет, перейти к Huawei Watch Face Designer или Facemaker.
