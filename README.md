# Huawei GT 5 Pro HUGO Style Watch Face

Проект оформляет базу для подготовки и дальнейшей сборки кастомного минималистичного циферблата в стиле HUGO для **HUAWEI Watch GT 5 Pro 46 mm**.

> Важно: репозиторий не содержит официально подтвержденный экспортированный `.hwt`. Текущий проект — заготовка для сборки через Huawei Watch Face Designer, Facemaker или HWT Tools. Формат GT 5 Pro может отличаться от старых форматов Huawei GT/GT2.

## Устройство

| Параметр | Значение |
| --- | --- |
| Модель | HUAWEI Watch GT 5 Pro |
| Размер | 46 mm |
| Экран | круглый |
| Разрешение | 466×466 px |
| Базовый тип циферблата | аналоговый, без виджетов |

## Дизайн

Базовая версия намеренно упрощена, чтобы увеличить шанс совместимости при сборке:

- черный круглый фон;
- красный верхний логотип/надпись в стиле HUGO;
- часовые метки по кругу;
- серая часовая стрелка;
- красная минутная и тонкая секундная стрелка;
- без шагов, погоды, пульса, уведомлений и других усложняющих виджетов.

## Порядок работы

1. Подготовьте локальные бинарные файлы из списка `docs/assets_to_create.md`.
2. Проверьте, что все изображения имеют целевое разрешение 466×466 px, кроме явно малых preview-иконок.
3. Поместите донорский файл в `assets/hwt/hugo_boss_black.gt-312881-fd38ad7b33.hwt`, если он доступен локально.
4. Изучите структуру донорского `.hwt` по инструкции `docs/hwt_structure_analysis.md`.
5. Откройте заготовку `project/` в выбранном инструменте: Huawei Watch Face Designer, Facemaker или HWT Tools.
6. Соберите экспортируемый файл `.hwt`.
7. Сохраните результат в `dist/huawei_gt5pro_hugo_style.hwt`.
8. Установите файл на часы по инструкции `docs/install_hwt_gt5pro.md`.

## Варианты сборки

### Huawei Watch Face Designer

Рекомендуемый официальный путь. Возможные ограничения: требуется Huawei Developer ID, верификация аккаунта и поддержка актуальной модели часов/разрешения 466×466.

### Facemaker

Подходит как визуальный конструктор, если поддерживает GT 5 Pro и экспорт `.hwt`. Возможный риск: экспорт может быть платным или ограниченным.

### HWT Tools / донорский `.hwt`

Подходит для технического анализа и экспериментов с ZIP-структурой `.hwt`. Риск: внутренний файл `com.huawei.watchface` может быть бинарным/подписанным, поэтому простая замена картинок не гарантирует рабочий результат.

## Установка

Подробная инструкция находится в `docs/install_hwt_gt5pro.md`. Коротко:

1. попробуйте локальную установку через Huawei Health / Huawei Themes;
2. если пункт скрыт — попробуйте перенос в папку `Huawei/Themes`;
3. если локальная установка недоступна — используйте альтернативный менеджер циферблатов.

## Риски совместимости

- GT 5 Pro использует разрешение 466×466 и может иметь формат проекта новее, чем старые гайды Huawei GT/GT2.
- Старый Huawei Watch Face Development Guide может описывать разрешения 390×390/454×454, поэтому XML-файлы в этом репозитории являются стартовой заготовкой, а не гарантированным финальным форматом.
- Простая пересборка ZIP или замена ресурсов в донорском `.hwt` может не работать, если бинарный модуль подписан или содержит встроенные ресурсы.
